# DevOps Internship Tasks & Complete Pipeline

This repository contains the end-to-end DevOps automation setup for the internship program.

## Features Included
- **Version Control & Branching Strategy**: Multi-branch setup (`main`, `dev`).
- **Containerization**: Dockerfile setup using lightweight Nginx Alpine base image.
- **Multi-Container Orchestration**: `docker-compose.yml` combining web server and Redis cache.
- **CI/CD Automation**: GitHub Actions workflows for continuous integration and automated deployment.
- **Infrastructure & Monitoring**: Cloud proxy configuration and Prometheus metrics setup.
